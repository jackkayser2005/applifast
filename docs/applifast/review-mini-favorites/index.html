Mini-player Apple favorites

Baseline e536995 (PR #44), candidate feat/apple-mini-favorites. The inactive Apple EQ slot becomes an add-only heart. The title-bar menu adds the current song, including when rolled up. Filled hearts remain read-only. Skin dimensions and transport controls are unchanged.

Matching native Windows captures use deterministic Apple demo data, built-in skin, identical pointer position, Reduce motion, theme and scale. Normal is 2x (550 × 232); narrow is 1x (275 × 116). Classic skins supply their own colors, so changing the application theme does not recolor this skin. Ready shows the hollow heart, pending/confirmed fill it, and an error restores it with refresh guidance in the marquee.

The open-menu captures are candidate-only because the baseline has no deterministic menu fixture. The rolled-up menu is exercised by a pointer regression, but is not pictured. HTML browser rendering, live-account additions, custom skins, restart acceptance and gaming tests remain separate gates. Stills do not verify motion.
