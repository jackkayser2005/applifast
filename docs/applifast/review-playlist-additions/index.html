Add songs, albums and the queue to Apple playlists

The existing picker now offers Apple library playlists marked writable. Sidebar drops append songs. An album's menu adds the whole album, after loading every track page. Right-click the queue's Save as a playlist button to append its current and upcoming songs. Left-click still creates a new playlist. Unsupported playlist editing remains unavailable. There are no changes to the shell, navigation, spacing or colors. The album menu gains Add to playlist and the queue save button gains a context menu.

New interaction states

Appending immediately adds both occurrences and their count. Confirmation retains all three copies. An ambiguous failure restores the original song and asks users to inspect the playlist before retrying. Add anyway preserves repeats; Cancel writes nothing.
