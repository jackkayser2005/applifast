PR #90: Apple Music documentation

Actual CI Jekyll output, baseline 8da79db, candidate 55c0450, captured in a separate disposable Chrome session on Windows. Both versions use the same route, viewport, theme, reduced-motion preference, zoom and neutral pointer. These are website captures, not new native app or real-account acceptance.
