Settings and keyboard shortcuts

Visible change: Keyboard shortcuts moves from the bottom About section to the Settings header. Apple mode lists quick navigation, refresh and queue keys, calls its mini player and Songs page by their Apple names, and omits unsupported favorite and playlist-editing bindings.

Baseline: Windows demo build 01c4a3a. Candidate: feat/apple-shortcuts. Captures match Apple sample data, Settings page, theme, window size, zoom, neutral pointer and Reduce motion. The open-dialog view uses the same fixture. These captures do not establish account playback or installer acceptance.

All 24 native Windows captures were inspected, including scrolling to the bottom of each dialog with the built-in demo input. Selector paths and PNG dimensions pass. Windows captures and keyboard regressions are separate from other-platform compilation and live MusicKit checks. No dependency, credential, storage setting or network destination is added.
