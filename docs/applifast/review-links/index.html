Shared Apple Music links

PR #29, candidate implementation 6332c2d on feat/apple-links. Baseline: native Windows demo build 463b1d0, PR #28.

User-visible scope: paste an Apple Music share URL into Search and press Enter, or pass it on launch. A song opens its album without starting playback. The play-uri command explicitly starts linked music. Unknown songs use their exact Apple resource, retaining library identity and original playback parameters. Failed reads leave the current queue intact; newer navigation/playback and sign-out invalidate older intents. Rejected CLI input is not echoed.

The interface layout, controls, styling and motion are unchanged. These native captures show matching album data, theme, size, neutral pointer and Reduce motion. Before opens the demo album directly with --demo-page because its CLI rejects Apple links. After reaches the same album through apple:track:library.i.demo0, using the new link route. This is a comparison of the resulting page, not proof of shared-URL network playback.

Parser and control-channel tests cover share URLs, catalog/library IDs, ambiguous song parameters and malformed inputs. App tests cover exact responses, authorization, stale answers, sign-out, playback cancellation and unchanged queues on failure. The demo test types a link in Search, presses Enter and checks ordinary text search afterwards. All eight native captures were inspected; selector paths and PNG dimensions pass. Fixtures retain some inherited Spotify labels. Real-account link playback, other-platform compilation and HTML browser rendering remain separate checks.

PR #29 scope ledger: the maintainer requested the complete Apple port and working navigation in the release checklist. This focused slice changes link behavior and documentation, without an interface redesign, dependency, credential entry, storage format, network destination, hosted service, telemetry or OS URL-handler registration. The account storefront determines availability. Short links, stations, videos and HTTP links are unsupported.
