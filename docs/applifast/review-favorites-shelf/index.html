Favorites in the left sidebar

PR #20, source 36de358, stacked on PR #19.

Visible change: Apple navigation adds Favorites, a scrolling shelf of loaded favorite songs, and Show all favorites. The dedicated page reuses the existing table without changing the Songs checkbox. Appearance adds a zero-to-ten shelf count, default five; zero hides the shelf while retaining navigation.

Baseline: Windows preview 2c6c576 (PR #19). Candidate: feat/apple-favorites-shelf. Captures match the same fourteen-song demo fixture, playing song, theme, zoom, window size and Reduce motion setting. The Favorites baseline is the existing filtered Songs view; the candidate is the deliberately separate Favorites page with the same five rows. Songs and Favorites use the same neutral pointer position. Settings uses the same scrollbar drag in each build; the added row changes its scroll extent.

Candidate states

All 32 native Windows frames were inspected. Selector paths and image dimensions are checked separately. These fixtures establish layout and interaction regressions, not real-account favorite completeness, playback, Home API results or resource acceptance. Favorite writes remain pending. No additional network endpoint, credential store or cache is added.
